# AIRust 0.2.6 implementation plan

Baseline: verified 0.2.5 at `cf5425b`. Add optional HNSW candidate retrieval while preserving the existing exact semantic, hybrid and context APIs. Existing defaults remain exact. New `hnsw` enables embeddings and pinned `hnsw_rs` 0.3.5, without a model, HTTP service or database.

Official metadata/source review compared instant-distance 0.6.1 (MIT/Apache-2.0, upstream archived), rust-cv hnsw 0.11 (MIT/Apache-2.0, older release), and hnsw_rs 0.3.5 (MIT/Apache-2.0, active upstream). Select hnsw_rs for configurable construction/search parameters and an existing maintained implementation. No third-party source is copied. Use its generic distance interface with one shared `Arc<Vec<f32>>` per point so the original semantic index and graph share vector buffers instead of duplicating their contents.

`HnswIndex` owns an existing `SemanticIndex` and derived HNSW topology. Build in sorted ID order with serial insertion; upstream 0.3.5 uses a fixed layer-generator seed. Re-score candidate vectors with the exact existing cosine function, threshold and stable ID tie-break. Configuration validates connection/layer/beam bounds before upstream calls. Expose whether search used HNSW or an exact fallback. Small indexes, scoped queries, oversized result requests, and excessive stale state use exact search. Filtering must never leak excluded content or silently search only an unfiltered top-K.

Updates and deletions modify the original semantic index and a tracked set of changed IDs. The immutable graph's outdated points are ignored and live changed entries are searched exactly. Explicit rebuild compacts stale vectors/topology and resets the overlay. Beyond the configured pending limit, use exact search until rebuild rather than silently losing update results. No mutable escape to the underlying index; return ownership with `into_semantic` when needed. Existing cache stores semantic vectors, not implementation-specific HNSW topology; rebuild ANN after a validated semantic-cache load.

Tests cover empty/small inputs, dimensions/model errors, exact scopes, thresholds/ties, update/delete/reinsert sequences, failed update atomicity, compaction and caller-owned source data. Benchmark exact versus ANN at 1k/10k/100k 384-dimensional vectors, record recall@10, construction and query times, memory, and post-update checks. Synthetic clustered/random workloads are not real semantic quality judgments. Full script, package, MSRV/consumer, CI and public artifact checks precede 0.2.7.

Primary references: [hnsw_rs repository and licenses](https://github.com/jean-pierreBoth/hnswlib-rs), [published crate](https://crates.io/crates/hnsw_rs/0.3.5), [generic HNSW API](https://docs.rs/hnsw_rs/0.3.5/hnsw_rs/hnsw/struct.Hnsw.html), [instant-distance](https://github.com/InstantDomain/instant-distance), [rust-cv implementation](https://docs.rs/hnsw/0.11.0/hnsw/struct.Hnsw.html), and [HNSW paper](https://arxiv.org/abs/1603.09320).

# AIRust 0.4.6 measurements

Read the [release report](../../CHANGES-0.4.6.md) and [protocol/worker manifests](../../validation-0.4.6/README.md). A is published 0.4.5 literal BM25/prefix delivery, C is 0.4.6 with explicit question preparation/leading context/distinct excerpts, and S is SQLite FTS5 plus BGE-M3 exact cosine/RRF. Every arm uses the same local Qwen, source scope and passage budgets. This is an authored document-question experiment, not independent human or production accuracy. New positive references come from only four already-known files; question-level intervals do not remove source-file correlation.

`summary.json` separates 210 exposed development questions and 72 fresh same-corpus holdout questions. `scored-rows.json` preserves every reply's technical checks, reference/fact proxies, costs and failures without full private questions, answers or source text. Exact quotations do not prove semantic correctness. The raw field `positive_unnecessary_abstentions` counts all abstentions on corpus-answerable questions, including retrieval misses; it does not prove that the model had sufficient delivered evidence. Unsupported-question null rates measure this protocol's abstention convention; a supported refusal can also be a valid answer. Requiring an authored reference ID can reject alternative valid evidence. Weak fact-pattern proxies can accept an answer about the wrong component; the semantic audit remains separate.

`assistant-audit.json` contains 72 preselected reply judgments. Variant labels were masked during review and judgments fixed/hashed before unmasking. The reviewer is the same assistant, not an independent human. Semantic support and exact quotation syntax are separate judgments. `raw-answer-sha256.json` identifies retained private complete replies and their actual prompt hashes.

`retrieval-timings.json` has five warm samples per question/arm. Context time includes source work, excerpt construction, serialization/IPC and shared context construction. Internal worker timing scopes differ. Warm S retrieval uses prepared vectors and excludes query embedding; reply end-to-end times include fresh S embeddings, retrieval, generation and quotation validation. Returned cache counters are retained. Lower costs with changed evidence or answer coverage are not equal-quality savings. Whole-worker RSS is not isolated index heap; Ollama process RSS and loaded Apple GPU/unified-memory residency must not be added as independent allocations.

The post-reply `ablation-summary.json` and `ablation-scored-rows.json` isolate all 12 combinations of literal/prepared queries, prefix/leading/compact excerpts and duplicate filtering on/off. They are descriptive diagnosis after the measured replies, not new tuning or additional LLM answer arms. Their source/lock/binary hashes are separate from the frozen main method. The two main configurations are checked against their original measured passages. Build the separate [ablation source](../../validation-0.4.6/ablation.rs) with its [manifest](../../validation-0.4.6/ablation.toml), supply the retained chunks/questions as two file arguments, then score spans against those same canonical entries. Ablation times are not published as quiet performance measurements.

`default-compatibility.json` compares every ordinary old/new response; the harness also checks verbatim versus common normalized baseline questions. `selection.json` counts exact duplicates and changed delivery. `validation.json` records completed native/Miri/API checks. `dependency-audit.json` retains informational maintenance notices as well as known-vulnerability counts. `experiment.json` discloses development selection, source/model/input hashes and measurement settings. `SHA256SUMS.json` covers all public JSON records.

Full source snapshots, complete model replies, initial failed attempts, frozen labels, query vectors, exact consumer locks, private audit inputs and logs remain under `local-lab/relevance-0.4.6/`, excluded from Git and crates.io. Public counters/hashes cannot independently reconstruct the private corpus. Earlier [0.4.5 measurements](../0.4.5/README.md) and the [0.4.4 comparison](../../HONEST-COMPARISON-0.4.4.md) remain unchanged.

# AIRust 0.4.5 measurements

See the [worker manifests and build instructions](../../validation-0.4.5/BUILD.md). Read the [release report](../../CHANGES-0.4.5.md) and [reproduction guide](../../validation-0.4.5/README.md) before interpreting these counters. A is published AIRust 0.4.4 BM25; C is 0.4.5 BM25 with optional compact/distinct delivery; S is SQLite FTS5 plus BGE-M3 exact-cosine reciprocal-rank fusion. Every arm uses the same local Qwen model and excerpt budgets. This is an authored document-question experiment, not independent human or production accuracy.

`summary.json` separates 162 exposed development questions and 48 fresh same-corpus holdout questions. `scored-rows.json` retains every answer's technical checks, reference/fact proxies, tokens and timing, including failures. There are no full answers, questions or private quotations in this public directory. A copied quotation is not proof of a correct answer. The raw field `positive_unnecessary_abstentions` counts abstentions on reference-answerable questions, including retrieval misses; its name does not establish that the model had enough delivered evidence. `reference_answer_proxy` additionally requires an authored reference ID; valid alternative evidence can therefore be missed. Bootstrap intervals describe these paired authored questions, not production uncertainty.

`assistant-audit.json` records 72 preselected anonymized reply judgments from the same assistant. Labels were fixed in a private frozen file before arm mapping was opened. They are a limited semantic review, not an independent audit. `retrieval-timings.json` contains five warm repeats per question/arm; context time includes IPC/serialization and context preparation. Worker subphase boundaries differ between implementations. `retriever-rss.json` is whole-worker RSS, not isolated index heap. `model-memory.json` samples the shared local Ollama process family and reports loaded model residency separately; do not add those figures as independent allocations on Apple unified memory.

`experiment.json` discloses the failed initial compaction comparison and the frozen method/model/input hashes. `selection.json` records exact-excerpt deduplication and changed delivery. `default-compatibility.json` compares 210 complete ordinary old/new retrieval responses. `validation.json` includes the incomplete large Miri attempt separately from four completed small cases. `dependency-audit.json` retains informational maintenance notices as well as known-vulnerability counts. `SHA256SUMS.json` covers the public JSON records.

Frozen inputs, canonical source snapshots, complete local model replies, initial failed results, model metadata, exact Cargo locks and detailed logs remain privately under `local-lab/evidence-0.4.5/`. They are excluded from Git and crates.io. Shared reproduction code is public, but private source data cannot be independently reconstructed from sanitized counters alone. The earlier [0.4.4 comparison](../../HONEST-COMPARISON-0.4.4.md) remains unchanged.

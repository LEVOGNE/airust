# AIRust 0.4.8 retained results

Read the [executed report](../../CHANGES-0.4.8.md), [method and applications](../../validation-0.4.8/README.md), [performance contract](../../CORE-PERFORMANCE.md) and [MCP boundaries](../../MCP.md).

- `retrieval-compatibility.json`, `retrieval-outcomes.json`, `retrieval-timings.json`, `retrieval-summary.json`, `retrieval-builds.json` and `retrieval-rss.json`: all 342 exposed questions in three configurations and both versions; 1,026 complete JSON comparisons and 10,260 warm timing samples. Question-level scalar outcomes contain no source passages.
- `query-summary.json`, `query-timings.json` and `query-heap-deltas.json`: ten authored fixtures, fourteen uninstrumented process runs and two separately instrumented runs. Allocation traffic is not index RAM; instrumented timings are not used for performance claims.
- `initial-query-summary.json`: the rejected first candidate, including the distinct-short-token slowdown. Raw initial measurements, source and exact binaries remain private.
- `mcp-reports.json`, `mcp-summary.json` and `mcp-compatibility.json`: twenty actual stdio processes, 1,380 schema-validated responses and 690 paired structured result/error comparisons by request ID. Only explicit release versions/status and expected schema URNs differ. Warm searches, startup, concurrent calls, source readbacks, errors and whole-child RSS remain separate scopes.
- `corpus-*.json`: complete retained-knowledge consistency checks in both versions, including updates/rebuilds/round trips/concurrent reads/aborts and source/export identities. Fixed source-code query strings are omitted from these public copies; full private results remain retained.
- `validation.json`, `benchmark-complete.json`, `frozen-inputs.json`, `method-sha256.json`, `method-amendment-*.json` and `resources.json`: executed gates, host/toolchains, input and executable identities, and the comparison/aggregation fixture corrections. Hashes identify data; they do not authenticate or anonymize it.

Baseline is exact registry 0.4.7; candidate is 0.4.8. Retrieval sources and ranking remain byte-identical on this corpus. There are no fresh LLM answers, new holdout labels, semantic-quality improvement or new PDF parser-speed claims. Raw private documents, contexts, RPC transcripts, all initial failed comparisons, DHAT traces and locks are outside the published crate. Aggregate counters cannot independently reproduce the private corpus. Small isolated improvements coexist with slightly slower mixed-query round trips and essentially unchanged process RAM.

# AIRust 0.4.0 evidence

These aggregates contain no original document text or private source paths. Complete raw files, fixtures, failures, code and binaries remain in the local PDF lab.

- `validation.json` records all gates and the difference between fresh and inherited checks.
- `documents.json` / `document-cases.json` record 35 fresh native extractions, exact snapshot/passages, page maps, JSON, source-change rejection, shared clones and 632 complete current/previous-core ranking comparisons on identical page entries.
- `sources.json` identifies retained original hashes and public URLs where available.
- `cost.json` / `cost-samples.json` record twelve fresh quiet restore/position/index verification processes, with source revision, timing boundaries and complete-process memory scope. Both SDK indexes and multiple buffers are retained by that verification workload.
- `retention.json` identifies the unchanged 167,942-entry canonical export, all eight checkpoints and separately retained new revisioned snapshots/page entries.
- `environment.json`, `backend.json` and dated audit files record compiler/profile, unchanged backend provenance and dependency checks.

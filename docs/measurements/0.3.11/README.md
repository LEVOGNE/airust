# AIRust 0.3.11 evidence

These files contain source-free aggregate outcomes and scoped resource measurements. Original document text and private source paths remain local.

- `paired-matching.json` records six fresh processes and all 24 fixed real-corpus cases. IDs/order and score/similarity bits are unchanged.
- `matching-properties.json` records 1,024 generated known-script cases across three matching strategies.
- `pdf-recheck.json` records fresh imports of all 33 retained PDFs and exact text/metadata/default-output comparisons.
- `soak-process.json`, `soak-results.json` and `soak-rss.json` record the 32-epoch real-corpus workload. A zero RSS reading at process termination remains in the raw samples; it is not a running-memory improvement.
- `readiness-cost.json` records 45 fresh-process real/synthetic scale, clone, concurrent-snapshot and SQLite workloads. Query algorithms and load/build/verification costs stay separate. Synthetic database samples are retained outside canonical knowledge.
- `retention.json` identifies the unchanged 160,085-entry canonical export and all seven retained checkpoints.
- `audit.json`, `backend-audit.json`, `backend.json` and `validation.json` record dated dependency checks, provenance and release gates. Final publication identity belongs to the release verification asset.

# AIRust 0.2.9 release contract

Baseline: artifact-verified 0.2.8, commit `795316597166edc05b3b4ca02b67b086de0e4db2`. Add optional intelligent reranking to the generic Rust library. Do not integrate or upgrade DenkMaps, add MCP tools, change existing search defaults, or implement the later 0.2.10–0.2.12 roadmap.

Use a provider-neutral pair-scoring boundary behind `reranking = []`. Borrow lexical/semantic/hybrid candidates and preserve their original evidence. Apply scope before a bounded candidate prefix, capture each entry once, validate selected inputs before inference, bound batches/UTF-8 pair bytes and expose candidate counts. Require finite ordered scores and a stable recipe. Keep deterministic original-order ties, strict default errors and explicitly unscored whole-prefix provider fallback. Do not bypass score thresholds or mix partial and unscored results.

Reuse maintained FastEmbed 7.7.1 for optional actual local multilingual cross-encoder inference. Supply a separate `local-reranking` feature with pinned size/hash-verified model assets, explicit runtime path and CPU thread count, no automatic downloads and no new default dependencies. Model weights are external. Fix the observed inability to combine local E5 and reranker sessions through a shared runtime environment. Keep external provider/native runtime ownership limits explicit.

Compare actual native scoring against the frozen 30-document/36-query 0.2.8 fixture. Rerank actual first-stage top-5/top-20 prefixes without adding judged positives, report Recall@N ceilings, unchanged baseline metrics, query-level improvements/regressions, no-answer failures, load and inference latency and OS CPU/RSS. Do not tune judgments or automatically enable reranking based on a small authored test. Compare maintained approaches and their licenses through primary sources; copy no third-party implementation.

Gate release with scoped/fallback/malformed-output/UTF-8/budget/recipe tests, an independent ordering reference and seeded cases, feature-isolated checks, strict Clippy/rustdoc, Rust 1.89 provider-independent and Rust 1.92 complete-feature checks, an independent consumer, cargo-semver-checks against 0.2.8, dependency audit, clean packaging/extracted tests, GitHub CI, publish dry run and exact registry/tag/release-asset verification. Update English README, API cookbook, migration/change reports, architecture/security and operating instructions with actual results and limitations.

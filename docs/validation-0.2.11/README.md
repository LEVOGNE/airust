# Independent 0.2.11 consumer

Copy consumer.toml to an external directory as Cargo.toml and consumer.rs as src/main.rs; run cargo +1.89.0 run. The exact registry dependency has no path override. It checks original APIs, advanced phrase/German analysis, reranking and both storage adapters through the same contract. The same source is also tested against a temporary local path before release. No application or model is needed.

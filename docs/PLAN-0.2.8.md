# AIRust 0.2.8 implementation plan

Baseline: published, artifact-verified 0.2.7 at `026046d`. Complete the requested release sequence with reproducible quality/performance tools, an independent optional `quality = []` API, complete English API recipes and a proposed upgrade guide for the existing DenkMaps 0.1.9 adapter. Do not integrate the new core into an application or add an MCP server.

Quality API: validated ID/grade judgments, explicit handling of unjudged results, Precision@K with fixed K denominator, Recall@K, reciprocal rank at K and exponential-gain nDCG@K. Grade zero is nonrelevant; grades 1..31 are relevant. Missing positive judgments make recall/nDCG undefined rather than falsely perfect. Reject duplicate ranked IDs within the evaluated window, invalid grades/IDs and zero cutoffs. Summaries expose macro means and the number of queries with defined denominators; reject mixed cutoffs/policies. No model or new dependency is required.

Preserve prior release fixtures unchanged. Add a separately versioned public hand-labeled fixture with multilingual paraphrases, literal identifiers, multiple graded sources, distractors and no-answer cases. Evaluate lexical, exact semantic and hybrid modes with real explicitly supplied E5 assets; preserve all per-query results and limits. These are authored smoke judgments, not an independent benchmark. Add graph/context/source/permission reference contracts, including evidence coverage, UTF-8 excerpts, deduplication and budgets. Do not confuse retrieval quality, logical truth or answer quality.

Review Criterion 0.8.2 and its statistical process. Keep dependency-free integration harnesses using Instant/black_box, explicit warmups, fixed samples and raw per-query records, plus OS CPU/RSS counters. They do not supply Criterion-style bootstrap confidence or significance tests. Run 1k/10k/100k workloads without concurrent compiler work; an optional million-entry lexical pass is separate. Report common/rare/missing queries, indexing and updates, graph/context costs and correctness. Retain earlier ANN recall warnings; do not rerun or hide unfavorable data merely to improve a headline.

Update CI from deprecated checkout v4 to the verified official v7.0.1 immutable commit, Node 24, disable persisted credentials and restrict token permissions to contents:read. Retain the existing unsafe-code prohibition and all minimum-Rust checks. Add quality contracts and examples to normal validation; native model inference remains an explicit local check with no compile-time model/runtime download.

Complete API-COOKBOOK and DENKMAPS-UPGRADE documents: feature choices, each public operation, provider/model identity, scopes, graph/source/context ownership, cache invalidation, CAS/history, ANN tradeoffs and quality metrics. Include a compiled application-neutral end-to-end example. Document the inspected existing DenkMaps adapter (SQLite revision reconciliation, tenant cache, private-map exclusions, Unicode legacy fallback), then propose a shadow-tested upgrade preserving SQLite authority and permissions. Model pools, off-thread inference, commit/revision checks, source freshness and rollback are explicit. MCP transport optimization remains separate follow-up work.

Finish with default/all-feature checks, strict Clippy/docs, isolated features, Rust 1.89/1.92, independent consumer, inspected clean package/extracted tests, candidate CI, publish dry run and registry/tag/asset verification. Then improve the separately requested existing DenkMaps MCP progress and communication behavior.

Primary references: [TREC precision/recall methodology](https://trec.nist.gov/pubs/trec30/papers/Overview-2021.pdf), [TREC exponential-gain nDCG](https://trec.nist.gov/pubs/trec20/papers/WEB.OVERVIEW.pdf), [reciprocal rank](https://trec.nist.gov/presentations/TREC8/removed/tsld051.htm), [Criterion 0.8.2](https://docs.rs/criterion/0.8.2/criterion/), [Criterion analysis](https://bheisler.github.io/criterion.rs/book/analysis.html), and [official checkout v7.0.1](https://github.com/actions/checkout/releases/tag/v7.0.1). No third-party source is copied.

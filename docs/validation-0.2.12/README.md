# Independent 0.2.12 consumer

Copy consumer.toml to an external directory as Cargo.toml and consumer.rs as src/main.rs; run cargo +1.89.0 run. It checks the exact registry dependency without a path override, old APIs, advanced text search, memory/SQLite storage and all four compact retrieval adapters with handwritten test vectors. The same source is tested against a temporary local path before release. No real application or model is needed.

# Independent 0.2.10 consumer

Copy consumer.toml to a fresh external directory as Cargo.toml and consumer.rs as src/main.rs, then run cargo +1.89.0 run with that manifest. The registry dependency is exact 0.2.10, without a path override. It checks original APIs, reranking and advanced German/phrase search. During development the same source was also checked against a temporary local path. No real application or model is needed.

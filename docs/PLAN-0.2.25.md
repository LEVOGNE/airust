# AIRust 0.2.25 acceptance plan

an optional bounded rule interpreter that proposes conclusions with explicit premises, sources, revision, conflicts and incomplete-result status.

Eleven integration cases cover thirty seeded BFS-reference closures with cycles, safe binding, deterministic proof DAGs, source integrity, missing support, explicit negative conflicts, hidden bridges, round/join/proposal/output limits and cooperative cancellation/deadlines/progress.

Require default/all-feature and isolated-feature tests, strict formatting/Clippy/rustdoc, Rust 1.89/1.92, patch compatibility, audit, independent consumer, package/dry-run, exact-commit CI, registry source/checksum/tag/asset verification. No application integration.
